1) GIT is a version control system that lets us track all the changes that we have made to our code from the file creation to file updates, everything. It keeps a memory of the date and time of when the changes were made and what the changes were so that developer can refer to them when having an issue while working on a particular code.
2) In order to push code on git there are a certain number of commands you need to follow :  
   First git init command to initialize the git repository.  
   Second git add file_name to add the file to the staging area.  
   Third git commit -m "message_for_the_commit" it is the record of the change.  
   Fourth git remote add origin repository_link to connect the local repository to the github repository.  
   Fifth git push -u origin main to push your code to the github repository.  
3) Markdown is a simple used to format plain text using different symbols like asterisk(*) and underscore(_). It is used to write content for the web.
4)  Markdown syntax and features :  
    Italics: surround the words with an underscore ex: _word_  
    Bold: surround the words with double asterisk ex: **word**  
    Headers: preface the phrase with a hash mark, place the same number of hash marks as the size of the heading ex:  
    # word
    ## word
    ### word
    #### word
    ##### word
    ###### word
    Links: there are two types inline link and reference link  
    inline link: wrap the line text in square brackets and the link in parantheses ex:  
    [Hey Google](www.google.com)  
    reference link: link is reference to another place in the document ex:  
    [Hey Google][link is here]
    
    [link is here]: www.google.com
    lists: there are 2 types ordered and unordered:  
    unordered list: preface each item in the list with an asterisk followed by a space ex:  
    * first project
    * git and markdown
      
    ordered list: preface with number followed by dot and space ex:
    1. first project
    2. markdown and github
      
    code block: surround the code or algorithm by 3 continuous backticks ex:  
    ```print("hello world")```
